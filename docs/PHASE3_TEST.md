## اختبار يدوي من الويب

افتحي: http://localhost:8082/login

### 1) إدارة الملصقات (مديرة)

1. سجّلي دخول **admin**
2. مستويات الملصقات → تأكدي وجود 3 مستويات
3. إدارة الملصقات → تأكدي وجود ملصقات نشطة

### 2) تدفق الواجب الكامل

1. **p3teacher** → إنشاء واجب → اختاري طالب + عنوان + وصف
2. **p3parent** → الواجبات → «تم الحل ✓»
3. **p3teacher** → تصحيح واجبات → أدخلي درجة → «تصحيح + AI»
4. **p3parent** → الواجبات → تأكدي ظهور الدرجة والملصق
5. **p3parent** → ملصقات الطفل → الملصق يظهر

### 3) تعديل ملصق (معلمة)

1. **p3teacher** → طلابي اليوم → ملف طالب
2. قسم الملصقات → ⋮ → تعديل أو إلغاء
