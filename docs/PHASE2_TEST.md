## اختبار يدوي من الويب

افتحي: http://localhost:8082/login

### 1) حضور/انصراف

1. سجّلي دخول **p2teacher**
2. تسجيل حضور → اختاري الطالب → حضور
3. سجّلي دخول **p2parent**
4. الحضور والغياب → تأكدي ظهور السجل

### 2) وجبات (تأكيد مزدوج)

1. **p2teacher** → تأكيد وجبات → غداء
2. **p2parent** → الوجبات → تأكيد تناول الوجبة
3. تأكدي ✓ للمعلمة وولي الأمر

### 3) بانرات + تقويم

1. **admin** → البانرات → أضيفي بانر
2. **admin** → التقويم السنوي → أضيفي حدث
3. **p2parent** → التقويم والبانرات → تأكدي الظهور

### 4) صور + موافقة

1. **p2teacher** → رفع صور → اختاري صورة
2. **admin** → موافقة الصور → موافقة
3. **p2parent** → ألبوم الصور → الصورة تظهر

> الصور تُحفظ محلياً في `backend/uploads` عندما MinIO متوقف.
